# Scratch Starter Project

A lightweight, Scratch-inspired starter environment built to explore drag-and-drop interactions, block-based logic, and the foundations of visual programming.  
This project focuses on replicating the core user experience of Scratch—clean UI, draggable action blocks, and a dedicated action panel—while keeping the codebase simple and easy to extend.

##  Live Demo
You can access the deployed version here:

**https://scratch-starter-project-dusky.vercel.app/**


## Overview
The project recreates the basic building blocks of a Scratch-style editor inside a browser environment.  
It includes:
- A block palette with draggable actions  
- A structured action panel where dropped blocks are organized  
- A stage area for future interaction and sprite behavior  
- A starter layout that can grow into a complete visual programming tool  

This setup serves as a foundation for experimenting with UI logic, block behavior, event flow, and interactive interfaces.

##  Key Features
- Smooth drag-and-drop mechanics  
- Organized action panel for dropped blocks  
- Clear and minimal UI inspired by Scratch  
- Ready-to-extend project structure  
- Basic sprite section and stage layout  
- Works on modern browsers.
